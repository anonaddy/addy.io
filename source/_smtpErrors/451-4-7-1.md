## What it means

The receiving server temporarily refused the email and asked the sender to try again later. The standard name for this status is "delivery not authorized, message refused", but the `4` at the start makes it temporary.

## Greylisting

The most common cause is greylisting. The first time a server sees a new sender, it rejects the email temporarily. Real mail servers retry after a few minutes and get through, while a lot of spam software never retries. Greylisting can also use other codes, such as `450 4.2.0`.

## Other causes

- The sending server is sending too fast and is being rate limited.
- The sender's IP address is temporarily listed on a blocklist.
- A temporary problem with the receiving server's spam checks.
- The address isn't available, with wording like "Recipient not available". Some providers send this for addresses that don't exist or have been blocked, so if it keeps happening, check the address is right.
- `454 4.7.1 Relay access denied` means the receiving server doesn't handle mail for that domain. The domain's MX records may point to the wrong server, or a new mail setup isn't finished yet.

## If you're the recipient

Usually nothing. Greylisted emails normally arrive within 5 to 30 minutes, which can delay sign-up codes and login links. If a code arrives late, request a new one and it should come straight through.

## If you're the sender

Let your server retry. If your sending software doesn't retry temporary failures, as some scripts and apps don't, send through a proper mail server or email provider.

## If you use addy.io

addy.io retries automatically if your inbox provider sends a temporary error, so the email is usually just delayed. See [Why are forwarded emails delayed?](/help/why-are-forwarded-emails-delayed/)
