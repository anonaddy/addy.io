## New

- Added new API endpoint to bulk delete failed deliveries, this can also be done through the web app - [https://app.addy.io/docs/#failed-deliveries-POSTapi-v1-failed-deliveries-delete-bulk](https://app.addy.io/docs/#failed-deliveries-POSTapi-v1-failed-deliveries-delete-bulk)

## Improvements

- Users on crypto subscriptions can now downgrade their subscription from the [subscription page](https://app.addy.io/settings/subscription)

## Fixes

- Fixed subscription_type in [account details](https://app.addy.io/docs/#account-details-GETapi-v1-account-details) API endpoint
