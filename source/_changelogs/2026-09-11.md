## New

- [Block Tracking Pixels](https://addy.io/blog/addy-io-now-blocks-tracking-pixels/) on Lite and Pro. Known tracking pixels are removed from forwarded HTML emails (enabled by default). See the [help article](https://addy.io/help/blocking-tracking-pixels-in-forwarded-emails/).
- Added dashboard graphs for tracking pixels blocked (Lite and Pro) and failed deliveries (all plans)
- Added a new [Leave Me Alone](https://addy.io/blog/addy-io-has-partnered-with-leave-me-alone/) perk for paid subscribers

## Improvements

- Added alias description to [failed delivery](https://app.addy.io/docs/#failed-deliveries-GETapi-v1-failed-deliveries) API endpoints
- Subscription renewing and ending emails now include the plan name.

## Fixes

- Fixed Gmail encoding that could break tracking pixel report links
- Fixed custom domain DNS checks timing out
- Fixed forwarded email banner CSS
- Fixed WebAuthn SHA1 errors
- Fixed duplicate blocklist entry error
- Fixed crypto coupon codes not showing as valid
- Fixed dashboard chart colours in dark mode and inline image Content-ID errors
