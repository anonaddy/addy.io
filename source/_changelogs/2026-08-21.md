## New

- Added [New Duo and Family plans](https://addy.io/blog/introducing-duo-and-family-plans/)
- Added ability to [share a custom domain](https://addy.io/help/duo-and-family-plans/#sharing-custom-domains) between family members on Duo and Family plans
- Added new conditions and actions to [Rules](https://app.addy.io/rules)

## Improvements

- Allow Rules to set empty description (e.g. to override "Created automatically by catch-all")

## Fixes

- Fixed issue where a coupon may have been null on a promo code for crypto subscriptions
- Fixed a "cannot read email on null" error where a user's account may have been deleted
- Fixed link colour in dark mode on Edit domain page
- Fixed aria label issue - [#917](https://github.com/anonaddy/anonaddy/issues/917)
