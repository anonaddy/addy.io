## New

- Alias labels - you can now add labels like Shopping, Banking, Newsletters, Work, etc. and filter by them.

## Improvements

- Moved domain check-sending route to the API - [https://app.addy.io/docs/#domains-POSTapi-v1-domains--id--check-sending](https://app.addy.io/docs/#domains-POSTapi-v1-domains--id--check-sending)

## Fixes

- Fixed a bug where an account could be downgraded to Free too soon after their subscription ended
- Fixed a small bug when trying to set a null text header on forwarded emails
- Fixed an issue where a blank line would cause formatting problems in encrypted emails
- Fixed an issue where large .eml attachments had the wrong content-type
- Fixed bug where an unknown payment_intent would cause an error
