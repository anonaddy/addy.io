## New

- Rules on Lite and Pro can [send a webhook](https://addy.io/blog/addy-io-rules-can-now-send-a-webhook/) when a matching email is accepted. See [Sending a webhook](https://addy.io/help/sending-a-webhook/).
- On Duo and Family plans, you can [deliver an alias to another member](https://addy.io/help/duo-and-family-plans/#delivering-aliases-to-family-members). You can allow them to reply and send, and a rule can forward to them.
- Added a new [Ente](https://addy.io/blog/addy-io-has-partnered-with-ente/) perk for paid subscribers
- Added a new [Obscura](https://addy.io/blog/addy-io-has-partnered-with-obscura/) perk for paid subscribers
- Added an Apps & Extensions page, and a short onboarding checklist for new accounts

## Improvements

- The web app theme now follows your system setting. You can still choose light or dark.
- You can hide alias domains from the create-alias list. Shared domains show a plan label, such as Lite or Pro or Pro only.
- You can hide intentional failed deliveries (a deactivated or deleted alias, or a blocked sender) from the Failed Deliveries page, the API, and the dashboard chart
- List-Unsubscribe can use the original header only, and addy.io does not add a header when none is present
- Rule actions that set an alias label now use a label list in the web app
- The edit alias page has an Active toggle
- Security key setup is clearer, and backup code instructions are easier to follow
- Improved tracking pixel removal

## Fixes

- Fixed a duplicate username error on registration
- Fixed rules that use a negated alias label condition
- Fixed pagination controls
- Fixed an extra line in the plain text email banner
- Fixed crypto coupon name checks
- Family members who receive a copy of an alias no longer see the owner's email banner actions
