## New

- A snapshot of account status and settings is now taken when an account is downgraded so that aliases, domains, usernames etc. can be automatically restored when resubscribing

## Improvements

- Improved error codes for quarantined failed deliveries

## Fixes

- Added missing client-side validation on new API key names - [#897](https://github.com/anonaddy/anonaddy/issues/897)
- Fixed bandwidth display bug on dashboard - [#894](https://github.com/anonaddy/anonaddy/issues/894)
- Fixed PGP encryption issue - [#899](https://github.com/anonaddy/anonaddy/issues/899)
